\# 💸 Smart Expense Analyzer



A modern personal finance dashboard built with Python and Streamlit to track income, analyze expenses, and manage monthly budgets.



\## ✨ Features



\- Add income and expense transactions

\- View total income, expenses, and net balance

\- Set monthly budgets by category

\- Receive alerts when spending reaches or exceeds a budget

\- Visualize expenses using interactive charts

\- Search and filter transaction history

\- Export transaction reports to CSV

\- Store transactions and budgets locally using SQLite

\- Dark modern dashboard interface



\## 🛠️ Tech Stack



\- Python

\- Streamlit

\- Pandas

\- Plotly

\- SQLite



\## 🚀 Run Locally



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/DevKumarBhatt/smart-expense-analyzer.git

&#x20;  cd smart-expense-analyzer

&#x20;  ```



2\. Create and activate a virtual environment:



&#x20;  ```powershell

&#x20;  python -m venv venv

&#x20;  .\\venv\\Scripts\\Activate.ps1

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



4\. Start the application:



&#x20;  ```bash

&#x20;  python -m streamlit run app.py

&#x20;  ```



5\. Open the local URL shown in your terminal.
